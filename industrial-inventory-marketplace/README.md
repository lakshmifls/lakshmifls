# B2B Industrial Inventory Marketplace — Phase 1

Phase 1 is a browser-based MVP for discovering industrial inventory and sending supplier enquiries.

## Included
- Industrial product catalog
- Search by product, category, supplier, or SKU
- Category filtering
- Product detail view
- Supplier information
- Add products to an enquiry basket
- Enquiry form with company/contact details
- Local browser persistence using localStorage
- Responsive layout for desktop and mobile
- Sample industrial inventory data

## Run locally
Open `index.html` in a browser. No server or paid service is required.

## Phase 1 scope
This version deliberately uses local sample data. Authentication, database, supplier onboarding, payments, RFQ workflow, admin dashboard, and production hosting are Phase 2+ features.

## Suggested next phase
Connect the catalog and enquiries to a backend database/API, then add supplier accounts and an RFQ workflow.
